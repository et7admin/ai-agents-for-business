# Sales agent plugin

The agent side of the [Sales manual](../../manual/sales/). Every skill carries out a numbered SOP and includes that SOP in its `references/` folder, so it works even when installed on its own.

## Role agents

| Agent | Use for | Skills |
|---|---|---|
| [`sales-development-rep`](agents/sales-development-rep.md) | New leads, prospect research, outreach and replies | `qualify-lead`, `research-prospect`, `draft-outreach` |
| [`account-executive`](agents/account-executive.md) | Call prep and summaries, proposals, follow-ups, handoffs | `research-prospect`, `prep-discovery-call`, `summarize-sales-call`, `build-proposal`, `draft-outreach`, `handoff-closed-deal` |
| [`sales-manager`](agents/sales-manager.md) | Pipeline review and forecast, win/loss, deal risk | `review-pipeline`, `analyze-win-loss`, `audit-crm-hygiene` |
| [`sales-operations`](agents/sales-operations.md) | CRM hygiene, reports, KPI calculations | `audit-crm-hygiene`, `review-pipeline` |

## Skills

| Skill | SOP | Max autonomy | What it does |
|---|---|---|---|
| [`qualify-lead`](skills/qualify-lead/SKILL.md) | SAL-SOP-001 | A3 | Grades an inbound lead A–D, picks the route, drafts the reply and CRM update |
| [`research-prospect`](skills/research-prospect/SKILL.md) | SAL-SOP-002 | A1 | Exclusion check, company snapshot, trigger events, contacts, angle and sequence |
| [`draft-outreach`](skills/draft-outreach/SKILL.md) | SAL-SOP-002 | A3 | Personalized emails and sequences; replies to interest, objections, referrals and opt-outs |
| [`prep-discovery-call`](skills/prep-discovery-call/SKILL.md) | SAL-SOP-003 | A2 | Call plan: context, attendees, hypotheses, scorecard gaps, questions, objections |
| [`summarize-sales-call`](skills/summarize-sales-call/SKILL.md) | SAL-SOP-003, 007 | A3 | Transcript → summary, scorecard, stage recommendation, CRM update, follow-up |
| [`build-proposal`](skills/build-proposal/SKILL.md) | SAL-SOP-004 | A2 | Readiness check, price build within policy, approval requests, proposal draft, error check |
| [`review-pipeline`](skills/review-pipeline/SKILL.md) | SAL-SOP-005 | A3 | Snapshot, coverage, changes, risk flags, suggested forecast categories, meeting agenda |
| [`handoff-closed-deal`](skills/handoff-closed-deal/SKILL.md) | SAL-SOP-006 | A3 | Paperwork check, cited handoff package, billing request, intro and welcome drafts |
| [`audit-crm-hygiene`](skills/audit-crm-hygiene/SKILL.md) | SAL-SOP-007 | A1 | Data-quality checks, per-owner fix lists, duplicates, stale deals, completeness score |
| [`analyze-win-loss`](skills/analyze-win-loss/SKILL.md) | SAL-SOP-008 | A1 | Evidence packs, reason classification, themes, recommendations |

"Max autonomy" is the most the skill may ever do. Every skill runs at **A1** (it drafts, you act) unless your `business-context.md` raises it. See [governance and autonomy](../../manual/00-company-foundations/governance-and-autonomy.md).

## Install

**Claude Code**
```bash
claude plugin marketplace add et7admin/ai-agents-for-business
claude plugin install sales@ai-agents-for-business
```

**Other Agent Skills tools:** copy `skills/*` into the skills folder your tool reads. Tools that support Agent Plugins 1.0 can load this folder directly (`plugin.json` is at its root).

**Chat apps:** use the packs in [`packs/sales/`](../../packs/sales/).

## Connectors

The plugin ships **without** connectors switched on, because which CRM, email and calendar you use is your choice. [`mcp.example.json`](mcp.example.json) lists remote MCP servers for common sales tools in Agent Plugins format. Copy the ones you use into `mcp.json` (Agent Plugins tools) or your tool's MCP settings. (Claude Code uses `"type": "http"` where this file says `"streamable-http"`.) Status and notes are in [tools-and-mcp.md](../../manual/sales/tools-and-mcp.md).
